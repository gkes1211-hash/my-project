# 5학년 2학기 수학 학습 앱

초등학교 5학년 아이가 휴대폰으로 수학 문제를 풀고, 틀린 이유를 알고, 비슷한 문제로 확실히 익히는 무료 웹앱입니다.
서버와 AI 없이 동작하며, 문제는 코드로 만든 "문제 틀"에서 숫자와 상황을 바꿔 끝없이 만듭니다.

## 내 컴퓨터에서 실행하기

필요한 것: [Node.js](https://nodejs.org) (LTS 버전). 그 밖에 설치할 것은 없습니다.

```
npm start      # 앱 켜기 → 브라우저에서 http://localhost:8000
npm test       # 자동 테스트 (문제 틀마다 난이도별 1000문제 검사)
```

## 폴더 구조

```
index.html               앱 시작 화면
css/style.css            디자인
js/app.js                화면 (홈, 소단원 선택, 문제 풀기, 오늘의 결과)
js/store.js              학습 기록 저장 (기기 안 localStorage)
js/curriculum.js         단원·소단원 목록
js/core/                 분수·소수 정확 계산, 어림하기, 무작위, 이름·물건 목록과 조사
js/engine/template.js    문제 틀 구조와 문제 만들기
js/engine/grader.js      채점 (자연수, 분수, 소수, 여러 개, 가장 작은/큰 수, 부등호, 객관식)
js/engine/diagnose.js    틀린 원인 진단 (오답 패턴 비교)
js/engine/session.js     무한 모드 (난이도 자동 조절, 최근 50문제 중복 방지, 골고루 출제)
js/templates/            단원별 문제 틀
js/ui/                   수식·그림(수직선, 수 카드, 표)·입력칸 그리기
scripts/serve.js         내 컴퓨터용 작은 웹 서버
tests/                   자동 테스트
```

## 새 문제 틀 추가하기

1. `js/templates/` 의 단원 파일에 `defineTemplate({...})`로 틀을 만든다. (필요한 항목은 `js/engine/template.js` 위쪽 설명 참고)
2. 파일 끝 `export default [...]` 목록에 넣는다.
3. 새 단원 파일이면 `js/templates/index.js`에 한 줄 추가한다.
4. `npm test`로 1000문제 검사를 통과하는지 확인한다.
