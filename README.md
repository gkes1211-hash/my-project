# 5학년 2학기 수학 학습 앱

초등학교 5학년 아이가 휴대폰으로 수학 문제를 풀고, 틀린 이유를 알고, 비슷한 문제로 확실히 익히는 무료 웹앱입니다.
서버와 AI 없이 동작하며, 문제는 코드로 만든 "문제 틀"에서 숫자와 상황을 바꿔 끝없이 만듭니다.

## 폴더 구조

```
index.html            앱 시작 화면
css/style.css         디자인
js/app.js             화면 (홈, 문제 풀기)
js/curriculum.js      단원·소단원 목록
js/core/              분수·소수 정확 계산, 무작위, 이름·물건 목록과 조사
js/engine/            문제 틀 구조와 문제 만들기, 채점, 틀린 원인 진단
js/templates/         단원별 문제 틀 (unit2.js ...)
tests/                자동 테스트 (틀마다 난이도별 문제 1000개 검사)
```

## 테스트 실행

```
npm test
```

## 새 문제 틀 추가하기

1. `js/templates/unitN.js`에 `defineTemplate({...})`로 틀을 만든다. (필요한 항목은 `js/engine/template.js` 위쪽 설명 참고)
2. 파일 끝 `export default [...]` 목록에 넣는다.
3. 새 단원 파일이면 `js/templates/index.js`에 한 줄 추가한다.
4. `npm test`로 1000개 검사를 통과하는지 확인한다.

## 개발 진행

- [x] 1단계: 계산 엔진, 문제 틀 구조, 자동 테스트, 2단원 (분수)×(자연수) 틀 3개
- [ ] 2단계: 틀렸을 때 흐름 (원인 고르기, 힌트 3단계, 비슷한 문제 5개, 도장)
- [ ] 3단계: 2단원 전체
- [ ] 4단계: 1단원 + 그림
- [ ] 5단계: 4단원, 6단원
- [ ] 6단계: 무한 모드 완성 (난이도 자동 조절, 복습)
- [ ] 7단계: 서술형, 기록, 설정
- [ ] 8단계: PWA, 배포
